# SmartCareClinic
SmartCareClinic is a healthCare system, which allows receptionists to register clients, book appointments and view the dashboard.

**FEATURES**
Secure login — passwords are hashed with Werkzeug (scrypt), never stored in plain text, with session-based authentication ("Remember me" support) and route protection (pages require login)
Patient registration — multi-step form (Personal → Medical → Emergency), with South African ID number validation against the entered Date of Birth, and an auto-generated patient number
Appointment booking — search patients by ID number, filter doctors by specialization, check doctor availability before booking, and a double-booking prevention rule (no doctor can be booked twice for the same date/time)
Dashboard — live stats (total patients, total doctors, today's appointments, upcoming appointments in the next 7 days), quick actions, and notifications (next appointment today, new registrations, no-shows)

**TECH STACK**
Backend: Python 3, Flask
Database: MySQL (via XAMPP), accessed with mysql-connector-python
Frontend: HTML, CSS, vanilla JavaScript (Jinja2 templating)
Security: Werkzeug password hashing, parameterized SQL queries (SQL injection prevention)
Testing: Python unittest

**DATABASE SCHEMA**
The system expects a MySQL database (default name: smartcareclinic) with 4 tables:

users — UserID, Username, PasswordHash, FullName, Role
patients — PatientNumber, FirstName, LastName, IDNumber, DateOfBirth, Gender, ContactNumber, Email, ResidentialAddress, MedicalAidProvider, MedicalAidNumber, EmergencyContact, RegistrationDate, Language, Allergies, ChronicConditions, BloodType, MaritalStatus
doctors — DoctorID, FullName, Specialization, PhoneNumber, Email
appointments — AppointmentNumber, AppointmentDate, AppointmentTime, DoctorID, PatientNumber, AppointmentStatus, Notes

**SETUP INSTRUCTIONS**
Install XAMPP and start MySQL from the XAMPP Control Panel.
Import/create the database — set up the 4 tables above in phpMyAdmin (http://localhost/phpmyadmin).
Install Python dependencies:
   pip install flask mysql-connector-python
Configure the database connection in db.py with your MySQL host, username, password, and database name.
Run the app:
   python app.py
Open in your browser: http://127.0.0.1:5000/
Running tests
python -m unittest test_app.py 
Known limitations / future improvements
Patient and appointment numbers are generated by reading the last value and incrementing it in Python; under simultaneous submissions this has a theoretical race condition
No self-service patient portal (booking is staff-only)
Doctor records are managed manually via phpMyAdmin (no in-app "Add Doctor" page yet)
No automated email/SMS reminders
